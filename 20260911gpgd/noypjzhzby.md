# 调理内分泌失调

调理内分泌失调需注意
　　对于内分泌失调的女性而言，健康的饮食从内到外的帮助调理，饮食调理是最好的方法。生活中很多常见的食物很多都是强效的调理食物。

　　1、新鲜蔬果

　　新鲜蔬果含有丰富的营养元素，如维生素A、维生素C。

　　2、含蛋白质的食物

　　鱼类是富含蛋白质的食物之一，而且还含有丰富的OMEGA - 3，Omega - 6和ω- 9油。这些油都是脂肪的最佳来源，每周食用两次鱼肉，将有助于保持内分泌系统的平衡。维生素E和抗氧化剂等，不仅有抗衰老等功效，而且还有助于调节内分泌失调。

　　3、大蒜

　　大蒜对内分泌失调有着重要作用。大蒜既能增强人体的免疫能力，又能提高人体抵御外界感染的能力。此外，它还能帮助调节血糖水平。每天嚼一至两个大蒜可有效维持内分泌平衡。

　　4、多吃绿色食物

　　绿色食物包括西兰花、生菜、芹菜等，它能够健肾、健肝、健脾。脾健康的话，能够很好地消化吸收对肾肝脾有益的食物，维持荷尔蒙分泌的平衡，避免身体出现不良状况。因此，黄色的食物材料是补充荷尔蒙的原动力。
内分泌失调吃什么好

　　材料：桃花(干品)1克，净猪蹄1只，粳米100克，细盐、酱油、生姜末、葱、香油、味精各适量。

　　做法：

　　（1）桃花焙干，研磨成碎末备用。

　　（2）粳米清洗干净，把猪蹄皮肉与骨头分开，放进铁锅中加适量清水旺火煮沸，然后转入小火慢慢炖煮成烂熟。
